# Shift Happens: Together

Portfolio source snapshot for a cooperative warehouse game built with Unity.

## Play on Steam

[Shift Happens: Together on Steam](https://store.steampowered.com/app/5173620/Shift_Happens_Together/)

Подробный стек и архитектурные решения: [TECHNOLOGIES.md](TECHNOLOGIES.md).

## Highlights

- Cooperative networking, lobby flow, player synchronization, and role-based tasks.
- Warehouse interactions: forklifts, pallet jacks, carts, shelves, orders, assembly, shipping, and repairs.
- Dynamic incidents including power failures, broken equipment, fires, thieves, damaged cargo, and rush orders.
- First- and third-person player systems, physics interactions, tools, melee combat, injuries, ragdolls, and IK.
- Career progression, tutorials, settings, HUD, minimap, audio routing, and developer playtest automation.

## Source layout

- `Assets/WarehouseDemo/Assets/Scripts` — main gameplay, networking, UI, audio, player, and world systems.
- `Assets/Scripts` — training and distribution-center systems.
- `Packages` — Unity package manifest and lock file.
- `ProjectSettings` — Unity project configuration.

## Portfolio note

This public repository is a source-code portfolio snapshot. Commercial Asset Store packages, large environment art, textures, baked lighting, generated captures, and build outputs are intentionally excluded. The Steam build contains the complete production content; this repository is not intended to reproduce that build without the licensed assets.
