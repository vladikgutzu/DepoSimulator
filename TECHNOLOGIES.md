# Технологии проекта Shift Happens: Together

## Основной стек

| Область | Технология |
|---|---|
| Движок | Unity 6000.4.7f1 |
| Язык | C# |
| Рендеринг | Universal Render Pipeline 17.4.0, Shader Graph 17.4.0 |
| Ввод | Unity Input System 1.19.0 |
| Камеры | Cinemachine 3.1.3 |
| Навигация | Unity AI Navigation 2.0.12 |
| Физика | Unity PhysX, CharacterController, Rigidbody, joints и ragdoll-системы |
| UI | uGUI 2.0.0 и UI Toolkit |
| Платформа релиза | Steam, Windows |

## Мультиплеер и онлайн-сервисы

- **Netcode for GameObjects 2.11.2** — синхронизация игроков, транспорта, предметов, физики и игровых событий.
- **Unity Authentication 3.6.1** — идентификация игроков.
- **Unity Lobby 1.3.0** — комнаты и подготовка кооперативной сессии.
- **Unity Relay 1.2.0** — подключение игроков без собственного выделенного сервера.
- **Vivox 16.5.0** — голосовая связь и её игровая маршрутизация.
- **Multiplayer Play Mode 2.0.2** — локальное тестирование нескольких клиентов.

## Игровые системы

- Компонентная архитектура взаимодействий через интерфейсы (`IInteractable`, `IGameEvent`) и специализированные контроллеры мира.
- Сетевые менеджеры для коробок, паллет, транспорта, магазина, оружия, лестниц и физических объектов.
- Ролевая кооперация, задания, заказы, сборка деталей, упаковка, доставка и карьерная прогрессия.
- Система динамических происшествий: поломки, пожар, отключение питания, воры, повреждённые грузы и срочные заказы.
- Персонаж от первого и третьего лица, IK рук, перенос предметов, травмы, ragdoll, инструменты и ближний бой.
- Пул аудиоисточников, Audio Mixer, пространственные звуки техники и окружения.

## Данные и производительность

- ScriptableObject-каталоги для предметов, заказов, оружия, обликов и аудио.
- JSON через Newtonsoft Json 3.2.2 для сериализации данных.
- Burst 1.8.29, Collections 6.4.0 и Mathematics 1.3.3 для производительных вычислений.
- Собственный бюджет теней, настройки качества, LOD и управление масштабом рендера.
- glTFast для импорта glTF-контента.

## Инструменты разработки

- Unity Test Framework и Performance Testing.
- Rider и Visual Studio.
- Собственные Editor-инструменты для настройки аудио, сетевого игрока, каталогов и сцен.
- Автоматизированные сценарии ручного тестирования и получения игровых скриншотов.

## Портфолио-версия

В публичный репозиторий включены оригинальный код, конфигурация и лёгкие данные. Коммерческие Asset Store-пакеты, крупные окружения, текстуры, запечённое освещение и сборки исключены. Полная версия доступна в [Steam](https://store.steampowered.com/app/5173620/Shift_Happens_Together/).
